# 007. 내 정보·설정

- 상태: Draft
- 관련 화면: 설정

## 배경과 목적

사용자가 자신의 계정 정보를 확인하고, 약관 등 안내를 보고, 로그아웃·탈퇴할 수 있게 합니다.

## 사용자 시나리오

1. 홈 오른쪽 위 "설정"을 누릅니다.
2. 프로필(닉네임, "Kakao 계정으로 로그인 중")을 봅니다.
3. 공지사항, 이용약관, 개인정보 처리방침, 앱 버전을 봅니다.
4. 로그아웃 또는 회원탈퇴를 합니다. (→ 001)

## 요구사항

- **FR-1**: 내 정보(닉네임, 로그인 수단)를 조회한다.

## 인수 조건

- **AC-1**
  - Given 로그인한 사용자
  - When 내 정보를 조회하면
  - Then 닉네임과 로그인 수단(`KAKAO`)을 받는다

## 범위 밖

- 로그아웃·탈퇴 자체 (001에서 다룸)

## 열린 질문

- [ ] 닉네임 변경 기능이 필요한가? (와이어프레임에는 없음)
- [ ] 공지사항을 서버에서 관리할지, 외부 페이지(Notion 등) 링크로 할지
- [ ] 이용약관·개인정보 처리방침 링크를 어디에 둘지
- [ ] 앱 버전은 앱 자체 값 표시로 충분한가? (강제 업데이트가 필요하면 서버 API 필요)
