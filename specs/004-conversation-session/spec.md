# 004. 대화 진행 (질문 듣기, 음성 답변)

- 상태: Draft
- 관련 화면: 대화 상세 조회 - 1 (Eva 음성 질문), 2 (사용자 음성 답변), 5 (다음 문제)

## 배경과 목적

실제 시험처럼 Eva가 영어로 질문을 읽어주고, 사용자는 녹음으로 답합니다. 중간에 나가도 이어서 풀 수 있어야 합니다.

## 사용자 시나리오

1. 대화에 들어가면 현재 문제(예: 1 / 15)가 보입니다.
2. Eva의 질문 음성이 재생됩니다. **다시 듣기는 1회** 가능합니다. 질문 글은 답변 전에는 보이지 않습니다.
3. 사용자가 녹음하고, 다시 누르면 답변이 끝납니다.
4. 답변의 텍스트와 질문 글이 나타나고, Eva의 답변 분석이 이어집니다. (→ 005)
5. "다음 문제"를 눌러 다음 질문으로 갑니다. 15번까지 반복합니다.
6. "목록"으로 나갔다가 다시 들어오면 마지막으로 답하지 않은 문제부터 이어집니다.

## 요구사항

- **FR-1**: 대화 상세에서 지금까지의 문항(질문, 답변, 피드백 상태)과 현재 문항 번호를 준다.
- **FR-2**: 각 문항의 질문 텍스트와 질문 음성을 준다. 질문 텍스트는 답변 제출 후에만 공개한다.
- **FR-3**: 질문 다시 듣기는 문항당 1회만 허용한다.
- **FR-4**: 사용자는 문항마다 음성 답변을 한 번 제출한다. 서버는 음성을 저장하고 텍스트로 바꾼다.
- **FR-5**: 문항은 순서대로만 답할 수 있다. 이전 문항에 답해야 다음 문항을 받는다.
- **FR-6**: 15번 문항까지 답하면 대화가 `COMPLETED`가 되고 종합 피드백 생성이 시작된다. (→ 006)

## 인수 조건

- **AC-1**
  - Given 새로 만든 대화
  - When 상세를 조회하면
  - Then 현재 문항은 1이고, 1번 질문 음성은 있지만 질문 텍스트는 없다
- **AC-2**
  - Given 1번 문항
  - When 음성 답변을 제출하면
  - Then 답변이 저장되고 질문 텍스트와 답변 텍스트를 받는다. 현재 문항은 2가 된다
- **AC-3**
  - When 이미 답한 문항에 다시 제출하면
  - Then 409를 받는다
- **AC-4**
  - Given 현재 문항이 3
  - When 5번 문항에 답을 제출하면
  - Then 409를 받는다
- **AC-5**
  - When 다시 듣기를 두 번째로 요청하면
  - Then 거절된다
- **AC-6**
  - Given 14개 답한 대화
  - When 15번에 답하면
  - Then 대화가 `COMPLETED`가 된다
- **AC-7**
  - When 다른 사용자의 대화에 접근하면
  - Then 403을 받는다
- **AC-8**
  - When 허용 형식이 아니거나 너무 긴 음성을 보내면
  - Then 400을 받는다

## 범위 밖

- 답변 시간 제한 (열린 질문)

## 열린 질문

- [ ] 다시 듣기 1회 제한을 서버가 관리할지, 앱이 관리할지
- [ ] 음성 형식(m4a/aac/wav)과 최대 길이 (제안: 최대 2분)
- [ ] 업로드 방식: multipart 직접 업로드 vs Presigned URL
- [ ] 음성 인식(STT)을 동기로 기다릴지, 비동기로 처리하고 폴링할지
- [ ] 질문 음성: 미리 만들어 저장 vs 요청 시 생성
- [ ] 문항 구성 규칙: 자기소개, 설문 주제 콤보, 돌발 주제, 롤플레이 비율
