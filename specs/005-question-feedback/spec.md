# 005. 문항별 피드백

- 상태: Draft
- 관련 화면: 대화 상세 조회 - 3 (질문·답변 텍스트), 4 (답변 분석)

## 배경과 목적

답변 하나가 끝날 때마다, 목표 등급에 비해 어느 수준인지와 어떻게 말하면 더 좋은지를 바로 알려줍니다.

## 사용자 시나리오

1. 답변을 제출하면 "Eva의 답변 분석" 카드가 나타납니다.
2. 예상 등급 → 목표 등급, 개선 방법, 예시 답변, 주요 단어를 봅니다.
3. 완료된 대화를 다시 열어도 같은 피드백을 볼 수 있습니다.

## 요구사항

- **FR-1**: 답변마다 피드백을 만든다. 항목은 다음과 같다.
  - 예상 등급 (`Grade`)
  - 목표 등급 (대화의 목표 등급)
  - 답변 디벨롭: 목표 등급 기준 개선 방법 목록 (한국어, 2~5개)
  - 추천 스크립트: 개선된 예시 답변 (영어)
  - 주요 단어: 추천 스크립트의 핵심 표현 목록
- **FR-2**: 피드백 생성은 시간이 걸리므로 상태(`PENDING`, `COMPLETED`, `FAILED`)를 준다.
- **FR-3**: 실패하면 다시 시도할 수 있다.
- **FR-4**: 한 번 만든 피드백은 다시 조회할 때 같은 내용을 준다.

## 인수 조건

- **AC-1**
  - Given 답변을 막 제출한 문항
  - When 문항을 조회하면
  - Then 피드백 상태는 `PENDING` 또는 `COMPLETED`이다
- **AC-2**
  - Given 피드백 생성이 끝난 문항
  - When 조회하면
  - Then FR-1의 모든 항목이 채워져 있다
- **AC-3**
  - Given 피드백 생성이 실패한 문항
  - When 재시도를 요청하면
  - Then 상태가 `PENDING`으로 바뀌고 다시 생성된다
- **AC-4**
  - Given 피드백이 아직 `PENDING`
  - When 다음 문제로 넘어가도
  - Then 다음 문항 진행은 막히지 않는다 *(제안 — 열린 질문)*
