# 001. 카카오 로그인·인증

- 상태: Draft
- 관련 화면: 스플래시, 설정 (로그아웃·회원탈퇴)

## 배경과 목적

사용자는 카카오 계정 하나로 가입과 로그인을 끝냅니다. 한 번 로그인하면 오래 유지되고, 언제든 로그아웃하거나 탈퇴할 수 있어야 합니다.

## 사용자 시나리오

1. 사용자가 스플래시에서 "kakao로 시작하기"를 누릅니다.
2. 앱이 카카오 SDK로 로그인하고, 받은 카카오 액세스 토큰을 서버에 보냅니다.
3. 처음이면 가입되고, 이미 가입했으면 로그인됩니다. 서버는 앱 전용 토큰을 돌려줍니다.
4. 앱은 토큰이 만료될 때까지 그대로 씁니다. 만료되면 다시 로그인합니다.
5. 설정에서 로그아웃하거나 회원탈퇴할 수 있습니다.

## 요구사항

- **FR-1**: 카카오 액세스 토큰으로 사용자를 확인하고, 없으면 새로 가입시킨다.
- **FR-2**: 로그인 성공 시 액세스 토큰 하나를 발급한다. 유효 기간은 30일이다. 리프레시 토큰과 재발급은 두지 않는다.
- **FR-3**: 로그인 응답에 이번에 새로 가입했는지 알려준다 (온보딩 표시용).
- **FR-4**: 로그아웃하면 그 토큰을 더 이상 쓸 수 없다.
- **FR-5**: 탈퇴하면 사용자 상태만 '탈퇴'로 바꾼다. 계정·대화 기록·음성 파일은 서버에 남긴다. 복구 기능은 없다.
- **FR-6**: 탈퇴한 카카오 계정으로 다시 로그인하면 새 계정으로 가입된다.
- **FR-7**: 첫 가입 시 카카오 닉네임을 기본 닉네임으로 쓴다.

## 인수 조건

- **AC-1** 신규 가입
  - Given 가입한 적 없는 카카오 사용자
  - When 유효한 카카오 토큰으로 로그인하면
  - Then 계정이 생성되고 액세스 토큰과 `isNewUser: true`를 받는다
- **AC-2** 기존 로그인
  - Given 이미 가입한 사용자
  - When 로그인하면
  - Then 새 계정 없이 같은 사용자로 토큰과 `isNewUser: false`를 받는다
- **AC-3** 잘못된 카카오 토큰
  - When 만료되었거나 잘못된 카카오 토큰으로 로그인하면
  - Then 401과 `INVALID_KAKAO_TOKEN`을 받는다
- **AC-4** 토큰 만료
  - Given 발급 후 30일이 지난 토큰
  - When 그 토큰으로 요청하면
  - Then 401과 `EXPIRED_TOKEN`을 받는다
- **AC-5** 로그아웃
  - When 로그아웃하면
  - Then 이후 그 토큰으로 요청하면 401과 `INVALID_TOKEN`을 받는다
- **AC-6** 탈퇴
  - When 탈퇴하면
  - Then 사용자 상태가 탈퇴가 되고, 이후 그 토큰으로 요청하면 401과 `INVALID_TOKEN`을 받는다. 데이터는 서버에 남아 있다
- **AC-7** 탈퇴 후 재가입
  - Given 탈퇴한 사용자
  - When 같은 카카오 계정으로 로그인하면
  - Then 새 계정이 생성되고 `isNewUser: true`, 이전 대화는 보이지 않는다
- **AC-8** 인증 없는 요청
  - When 토큰 없이 인증이 필요한 API를 부르면
  - Then 401과 `UNAUTHORIZED`를 받는다
- **AC-9** 카카오 서버 오류
  - Given 카카오 서버가 응답하지 않음
  - When 로그인하면
  - Then 502와 `KAKAO_SERVER_ERROR`를 받는다

## 범위 밖

- 카카오 외 로그인 (애플, 구글 등)
- 이메일/비밀번호 로그인
- 리프레시 토큰, 토큰 재발급
- 탈퇴 계정 복구
