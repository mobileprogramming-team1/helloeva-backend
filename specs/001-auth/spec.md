# 001. 카카오 로그인·인증

- 상태: Draft
- 관련 화면: 스플래시, 설정 (로그아웃·회원탈퇴)

## 배경과 목적

사용자는 카카오 계정 하나로 가입과 로그인을 끝냅니다. 로그인 상태를 유지하면서 언제든 로그아웃하거나 탈퇴할 수 있어야 합니다.

## 사용자 시나리오

1. 사용자가 스플래시에서 "kakao로 시작하기"를 누릅니다.
2. 앱이 카카오 SDK로 로그인하고, 받은 카카오 액세스 토큰을 서버에 보냅니다.
3. 처음이면 가입되고, 이미 가입했으면 로그인됩니다. 서버는 앱 전용 토큰을 돌려줍니다.
4. 앱은 토큰이 만료되면 자동으로 재발급받습니다.
5. 설정에서 로그아웃하거나 회원탈퇴할 수 있습니다.

## 요구사항

- **FR-1**: 카카오 액세스 토큰으로 사용자를 확인하고, 없으면 새로 가입시킨다.
- **FR-2**: 로그인 성공 시 액세스 토큰과 리프레시 토큰을 발급한다.
- **FR-3**: 리프레시 토큰으로 두 토큰을 새로 발급한다. 사용한 리프레시 토큰은 다시 쓸 수 없다.
- **FR-4**: 로그아웃하면 현재 토큰들을 더 이상 쓸 수 없다.
- **FR-5**: 탈퇴하면 계정이 비활성화되고 카카오 연결이 끊긴다.
- **FR-6**: 첫 가입 시 카카오 닉네임을 기본 닉네임으로 쓴다.

## 인수 조건

- **AC-1** 신규 가입
  - Given 가입한 적 없는 카카오 사용자
  - When 유효한 카카오 토큰으로 로그인하면
  - Then 계정이 생성되고 액세스·리프레시 토큰을 받는다
- **AC-2** 기존 로그인
  - Given 이미 가입한 사용자
  - When 로그인하면
  - Then 새 계정 없이 같은 사용자로 토큰을 받는다
- **AC-3** 잘못된 카카오 토큰
  - When 만료되었거나 잘못된 카카오 토큰으로 로그인하면
  - Then 401과 `INVALID_KAKAO_TOKEN`을 받는다
- **AC-4** 토큰 재발급
  - Given 유효한 리프레시 토큰
  - When 재발급을 요청하면
  - Then 새 토큰 쌍을 받고, 이전 리프레시 토큰은 다시 쓸 수 없다
- **AC-5** 로그아웃
  - When 로그아웃하면
  - Then 이후 그 액세스 토큰으로 요청하면 401을 받는다
- **AC-6** 탈퇴
  - When 탈퇴하면
  - Then 이후 그 토큰으로 요청하면 401을 받고, 사용자 정보는 조회되지 않는다
- **AC-7** 인증 없는 요청
  - When 토큰 없이 인증이 필요한 API를 부르면
  - Then 401과 `UNAUTHORIZED`를 받는다

## 범위 밖

- 이메일/비밀번호 로그인
