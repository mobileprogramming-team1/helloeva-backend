# 006. 종합 피드백

- 상태: Draft
- 관련 화면: 대화 상세 조회 - 6 (전체 피드백 보기), 7 (종합 피드백 1), 8 (종합 피드백 2 · 마무리)

## 배경과 목적

15문항을 모두 마치면 시험 전체를 바탕으로 예상 등급과 영역별 수준, 다음에 공부할 것을 알려줍니다.

## 사용자 시나리오

1. 마지막 문제의 피드백 아래 "전체 피드백 보기"를 누릅니다.
2. "수고하셨어요! 15문제를 모두 마쳤어요." 메시지와 종합 피드백 카드를 봅니다.
3. 마지막에 Eva의 마무리 메시지가 나옵니다.

## 요구사항

- **FR-1**: 대화가 `COMPLETED`가 되면 종합 피드백을 만든다. 항목은 다음과 같다.
  - 종합 예상 등급, 목표 등급
  - 영역별 평가: 유창성, 어휘, 문법, 내용 구성 (각 0~100)
  - 잘한 점 (목록)
  - 보완할 점 (목록)
  - 추천 학습 (목록)
  - 자주 쓴 표현 (목록)
  - 마무리 메시지
- **FR-2**: 생성 상태(`PENDING`, `COMPLETED`, `FAILED`)를 준다.
- **FR-3**: 종합 예상 등급은 대화 목록에도 보인다. (→ 003)

## 인수 조건

- **AC-1**
  - Given 15문항을 모두 답한 대화
  - When 종합 피드백을 조회하면
  - Then 상태가 `PENDING` 또는 `COMPLETED`이다
- **AC-2**
  - Given 생성이 끝난 종합 피드백
  - When 조회하면
  - Then FR-1의 모든 항목이 채워져 있고, 영역 점수는 0~100이다
- **AC-3**
  - Given 아직 진행중인 대화
  - When 종합 피드백을 조회하면
  - Then 409를 받는다
- **AC-4**
  - Given 생성에 실패한 종합 피드백
  - When 재시도하면
  - Then 다시 생성된다
