# 004. 대화 진행 (질문 듣기, 음성 답변)

- 관련 화면: 대화 상세 조회 - 1 (Eva 음성 질문), 2 (사용자 음성 답변), 5 (다음 문제)

## 배경과 목적

실제 시험처럼 Eva가 영어로 질문을 읽어주고, 사용자는 녹음으로 답합니다. 중간에 나가도 이어서 풀 수 있어야 합니다.

## 사용자 시나리오

1. 대화에 들어가면 현재 문제(예: 1 / 15)가 보입니다.
2. Eva의 질문 음성이 재생됩니다. **다시 듣기는 1회** 가능합니다 (실제 OPIc처럼 질문이 끝난 뒤 5초 이내 — 화면에서 처리). 질문 글은 답변 전에는 보이지 않습니다.
3. 사용자가 녹음하고, 다시 누르면 답변이 끝납니다.
4. 잠시 기다리면 답변의 텍스트, 질문 글, Eva의 답변 분석이 한 번에 나타납니다. (→ 005)
5. "다음 문제"를 눌러 다음 질문으로 갑니다. 15번까지 반복합니다.
6. 15번의 답변 분석 아래 "전체 피드백 보기"를 누르면 종합 피드백으로 갑니다. (→ 006)
7. "목록"으로 나갔다가 다시 들어오면 마지막으로 답하지 않은 문제부터 이어집니다.

## 요구사항

- **FR-1**: 대화 상세에서 15문항 전체(질문 음성, 답한 문항의 질문 텍스트·답변·답변 분석)와 현재 문항 번호를 준다.
- **FR-2**: 각 문항의 질문 텍스트와 질문 음성을 준다. 질문 텍스트는 답변 제출 후에만 공개한다.
- **FR-3**: 질문 다시 듣기는 현재 문항에서, 답변 전에, 문항당 1회만 허용한다. 횟수는 서버가 관리한다.
- **FR-4**: 사용자는 문항마다 음성 답변을 한 번 제출한다. 서버는 음성을 저장하고 바로 텍스트로 바꿔 응답한다. 음성 인식이 실패해도 서버가 다시 처리해서 응답한다.
- **FR-5**: 문항은 순서대로만 답할 수 있다. 이전 문항에 답해야 다음 문항을 받는다.
- **FR-6**: 답변 제출 요청 안에서 음성 인식과 답변 분석(→ 005)까지 끝내고 한 번에 응답한다. 따로 상태를 관리하거나 기다리는 API를 두지 않는다.
- **FR-7**: 15번까지 답해도 대화는 `IN_PROGRESS`다. 종합 피드백이 만들어져야 `COMPLETED`가 된다. (→ 006)
- **FR-8**: 음성 파일은 m4a·aac·wav, 최대 2분·10MB까지 받는다.
- **FR-9**: AI 작업(질문 음성 생성, 음성 인식)이 실패해도 서버가 성공할 때까지 다시 처리한다. 앱은 실패를 다루지 않는다.
- **FR-10**: 대화 상세는 대화 화면에 들어올 때 한 번만 받는다. "다음 문제"는 받아둔 목록에서 다음 문항을 꺼내 쓰며 API를 호출하지 않는다.

## 인수 조건

- **AC-1**
  - Given 새로 만든 대화
  - When 상세를 조회하면
  - Then 15문항이 모두 오고 현재 문항은 1이다. 모든 문항에 질문 음성이 있고, 질문 텍스트는 없다
- **AC-2**
  - Given 1번 문항
  - When 음성 답변을 제출하면
  - Then 답변이 저장되고 질문 텍스트, 답변 텍스트, 답변 분석을 한 번에 받는다. 현재 문항은 2가 된다
- **AC-3**
  - When 이미 답한 문항에 다시 제출하면
  - Then 409와 `QUESTION_ALREADY_ANSWERED`를 받는다
- **AC-4**
  - Given 현재 문항이 3
  - When 5번 문항에 답을 제출하면
  - Then 409와 `QUESTION_NOT_CURRENT`를 받는다
- **AC-5**
  - When 다시 듣기를 두 번째로 요청하면
  - Then 409와 `REPLAY_LIMIT_EXCEEDED`를 받는다
- **AC-6**
  - Given 14개 답한 대화
  - When 15번에 답하면
  - Then 현재 문항은 없어지고, 대화는 여전히 `IN_PROGRESS`다
- **AC-7**
  - When 다른 사용자의 대화에 접근하면
  - Then 403을 받는다
- **AC-8**
  - When 허용 형식이 아니거나 너무 긴 음성을 보내면
  - Then 400을 받는다
- **AC-9**
  - Given 이미 답한 문항
  - When 다시 듣기를 요청하면
  - Then 409와 `QUESTION_ALREADY_ANSWERED`를 받는다
