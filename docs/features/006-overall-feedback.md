# 006. 종합 피드백

- 관련 화면: 대화 상세 조회 - 6 (전체 피드백 보기), 7 (종합 피드백 1), 8 (종합 피드백 2 · 마무리)

## 배경과 목적

15문항을 모두 마친 사용자가 원할 때, 시험 전체를 바탕으로 예상 등급과 영역별 수준, 다음에 공부할 것을 알려줍니다.

## 사용자 시나리오

1. 15번 문제의 답변 분석 아래 "전체 피드백 보기"를 누릅니다.
2. Eva가 결과를 정리하는 동안 잠시 기다립니다.
3. "수고하셨어요! 15문제를 모두 마쳤어요." 메시지와 종합 피드백 카드를 봅니다.
4. 마지막에 Eva의 마무리 메시지가 나옵니다.

## 요구사항

- **FR-1**: 종합 피드백은 사용자가 요청("전체 피드백 보기")해야 만든다. 15문항에 모두 답한 대화만 요청할 수 있다.
- **FR-2**: 종합 피드백 항목은 다음과 같다.
  - 종합 예상 등급, 목표 등급
  - 영역별 평가: 유창성, 어휘, 문법, 내용 구성 (각 0~100)
  - 잘한 점 (목록)
  - 보완할 점 (목록)
  - 추천 학습 (목록)
  - 자주 쓴 표현 (목록)
  - 마무리 메시지 (AI가 결과에 맞춰 작성)
- **FR-3**: 요청 안에서 종합 피드백을 만들어 응답에 바로 담는다. 상태 관리는 하지 않는다. AI 호출이 실패하면 서버가 다시 시도한다.
- **FR-4**: 종합 피드백 생성이 끝나면 대화가 `COMPLETED`가 된다. 종합 예상 등급은 대화 목록에도 보인다. (→ 003)
- **FR-5**: 이미 만들어진 종합 피드백을 다시 요청하면, 새로 만들지 않고 그 결과를 돌려준다.

## 인수 조건

- **AC-1**
  - Given 15문항을 모두 답한 대화
  - When 종합 피드백을 요청하면
  - Then 응답에 FR-2의 모든 항목이 채워진 종합 피드백을 받고, 대화는 `COMPLETED`가 된다
- **AC-2**
  - Given 종합 피드백이 만들어진 대화
  - When 종합 피드백을 조회하면
  - Then 만들 때와 같은 내용을 받고, 영역 점수는 0~100이다
- **AC-3**
  - Given 15문항을 다 답하지 않은 대화
  - When 종합 피드백을 요청하면
  - Then 409와 `QUESTIONS_NOT_ALL_ANSWERED`를 받는다
- **AC-4**
  - Given 종합 피드백을 만들지 않은 대화
  - When 종합 피드백을 조회하면
  - Then 409와 `OVERALL_FEEDBACK_NOT_REQUESTED`를 받는다
- **AC-5**
  - Given 종합 피드백이 이미 만들어진 대화
  - When 다시 요청하면
  - Then 새로 만들지 않고 기존 결과를 받는다
