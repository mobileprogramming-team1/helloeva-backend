# 002. 대화 생성 (목표 등급 + 배경 설문)

- 관련 화면: 대화 생성 - 1 (목표 등급), 대화 생성 - 2 (배경 설문 1/8 ~ 8/8)

## 배경과 목적

실제 OPIc처럼 사용자의 목표 등급과 배경 설문 답을 바탕으로 질문을 구성하기 위해, 대화를 만들 때 이 정보를 받습니다.

## 사용자 시나리오

1. 홈에서 "+ 새 대화 시작"을 누릅니다.
2. 목표 등급 9개 중 1개를 고릅니다.
3. 배경 설문 8단계를 차례로 답합니다. "이전"으로 돌아가 바꿀 수 있습니다.
4. 마지막 단계에서 "완료"를 누르면 대화가 만들어지고 바로 1번 문제(자기소개)가 시작됩니다.

## 배경 설문 문항

| 단계 | 문항 | 선택 방식 | 선택지 |
|---|---|---|---|
| 1 | 직업 | 1개 | 사업/회사 근무, 재택근무/재택사업, 교사/교육자, 일 경험 없음 |
| 2 | 학생 여부 | 1개 | 예, 아니요 |
| 3 | 최근 수강 강의 | 1개 | 학위 과정 수업, 전문 기술 향상을 위한 평생학습, 어학 수업, 수강 후 5년 이상 지남 |
| 4 | 거주 형태 | 1개 | 개인 주택·아파트에 혼자 거주, 친구·룸메이트와 거주, 가족과 거주, 학교 기숙사, 군대 막사·군 시설 |
| 5 | 여가 활동 | 복수, 최소 2개 | 영화 보기, 클럽/나이트클럽 가기, 공연 보기, 콘서트 보기, 박물관 가기, 공원 가기, 캠핑하기, 해변 가기, 스포츠 관람, 게임하기, SNS에 글 올리기, 친구들과 문자 대화하기, 주거 개선, 술집/바에 가기, 카페/커피 전문점 가기, 쇼핑하기, TV 시청하기, 리얼리티 쇼 시청하기, 뉴스 보기/듣기, 요리 관련 프로그램 시청하기, 체스하기, 당구, 시험 대비 과정 수강하기, 구직 활동하기, 자원봉사하기, 드라이브하기 |
| 6 | 취미·관심사 | 복수, 최소 1개 | 아이에게 책 읽어주기, 음악 감상하기, 악기 연주하기, 혼자 노래 부르기/합창하기, 춤추기, 글쓰기, 그림 그리기, 요리하기, 반려동물 키우기, 주식 투자하기, 신문 읽기, 여행 관련 잡지·블로그 읽기, 독서, 사진 촬영하기 |
| 7 | 운동 | 복수, 최소 1개 ("운동을 전혀 하지 않음"도 다른 운동과 함께 선택 가능) | 농구, 야구/소프트볼, 축구, 미식축구, 하키, 크리켓, 골프, 배구, 테니스, 배드민턴, 탁구, 수영, 자전거, 스키/스노보드, 아이스 스케이트, 조깅, 걷기, 요가, 하이킹/트레킹, 낚시, 헬스, 태권도, 운동 수업 수강하기, 운동을 전혀 하지 않음 |
| 8 | 휴가·출장 | 복수, 최소 1개 | 집에서 보내는 휴가, 국내 출장, 해외 출장, 국내 여행, 해외 여행 |

## 요구사항

- **FR-1**: 목표 등급(9개 중 1개)과 배경 설문 답을 "완료" 때 한 번에 받아 대화를 만든다.
- **FR-2**: 5~8단계 선택 개수의 합은 **최소 12개**여야 한다. (화면의 "누적 N / 12")
- **FR-3**: 각 단계의 최소 선택 개수를 지켜야 한다.
- **FR-4**: 만들어진 대화는 15개 문항을 가지며, 상태는 `IN_PROGRESS`이다.
- **FR-5**: 설문 선택지 목록(단계, 문구, 선택 방식, 최소 개수)을 서버가 내려준다. 앱에 하드코딩하지 않는다.
- **FR-6**: 대화를 만들 때 15문항의 질문과 질문 음성을 모두 만든 뒤 응답한다 (음성은 병렬로 만들고, 시간이 조금 걸려도 된다). 1번은 고정된 자기소개 질문이다.
- **FR-7**: 2~15번 문항은 실제 OPIc 구성을 따른다 — 같은 주제로 이어지는 묶음(콤보), 설문과 무관한 돌발 주제, 롤플레이, 마지막 고난도 문항.

## 인수 조건

- **AC-1**
  - Given 목표 등급과 조건을 만족하는 설문 답
  - When 대화를 만들면
  - Then 회차 번호가 붙은 대화가 `IN_PROGRESS`로 생성되고, 1번 문항의 질문 음성을 바로 재생할 수 있다
- **AC-2**
  - When 5~8단계 합계가 12개 미만이면
  - Then 400과 필드 오류를 받는다
- **AC-3**
  - When 여가 활동을 1개만 고르면
  - Then 400과 필드 오류를 받는다
- **AC-4**
  - When 없는 선택지 코드를 보내면
  - Then 400을 받는다
- **AC-5**
  - Given 이미 대화가 3개 있는 사용자
  - When 새로 만들면
  - Then 회차는 4가 된다
- **AC-6**
  - When 운동에서 "운동을 전혀 하지 않음"과 "걷기"를 함께 고르면
  - Then 정상적으로 생성된다

## 범위 밖

- 설문 답을 저장해두고 다음 생성 때 자동으로 채우기 (후보)
- 실제 OPIc의 난이도 자가 평가(Self-Assessment) 단계
