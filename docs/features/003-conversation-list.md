# 003. 대화 목록

- 관련 화면: 대화 목록 조회(홈), 대화 목록 조회(홈) - 빈 상태

## 배경과 목적

사용자가 지금까지 본 대화를 한눈에 보고, 진행중인 것은 이어서 하고, 끝난 것은 결과를 다시 볼 수 있게 합니다.

## 사용자 시나리오

1. 로그인 후 홈에서 내 대화 목록을 봅니다.
2. "전체 / 진행중 / 완료" 탭으로 거릅니다.
3. 항목을 누르면 진행중이면 이어서 풀고, 완료면 결과를 봅니다.

## 요구사항

- **FR-1**: 내 대화만 최신순(회차 내림차순)으로 보여준다.
- **FR-2**: 상태(`IN_PROGRESS`, `COMPLETED`)로 거를 수 있다. 거르지 않으면 전체.
- **FR-3**: 항목마다 회차, 목표 등급, 생성일, 상태를 준다. 완료된 항목은 **종합 예상 등급**도 준다.
- **FR-5**: 대화는 종합 피드백 생성이 끝나야 완료다. 15문항을 다 풀었어도 종합 피드백 전이면 진행중이다. (→ 006)
- **FR-6**: 페이지 나누기 없이 전체를 한 번에 준다.
- **FR-4**: 필터 조건에 맞는 전체 개수를 준다. ("대화 4개")

## 인수 조건

- **AC-1**
  - Given 대화 4개 (진행중 1, 완료 3)
  - When 전체를 조회하면
  - Then 4개가 회차 내림차순으로 오고 개수는 4이다
- **AC-2**
  - When 완료만 조회하면
  - Then 3개가 오고, 각각 종합 예상 등급이 있다
- **AC-3**
  - Given 대화가 없는 사용자
  - When 조회하면
  - Then 빈 목록과 개수 0을 받는다
- **AC-4**
  - Given 다른 사용자의 대화
  - When 조회하면
  - Then 내 목록에 나오지 않는다
